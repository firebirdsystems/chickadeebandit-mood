# Mood Journal

A [Chickadee Bandit](https://chickadeebandit.com/app-library/mood) app.

Daily private mood and energy check-ins with gentle prompts and trend views over time. Entries stay private by default; opt in to share trends with a parent or partner.

## Features

- Daily mood and energy check-ins.
- Gentle journaling prompts.
- Trend views over time.
- Private by default; opt in to share trends.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-mood/releases/latest/download/bundle.json
```
